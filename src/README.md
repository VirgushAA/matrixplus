# Matrix++

Библиотека базовых операций над матрицами на C++.

Учебный проект для практики объектно-ориентированного программирования и работы с C++.

## Возможности
- создание и хранение матриц;
- сравнение матриц;
- сложение, вычитание, умножение и деление;
- транспонирование;
- вычисление определителя, минора и алгебраических дополнений;
- вычисление обратной матрицы;
- проверка размеров матриц и обработка ошибок;
- Изменение размеров матрицы.

## Сборка

Сборка выполняется с помощью `make`:

```bash
    make
```
Команда собирает динамическую библиотеку и запускает тесты.

## Тесты

Для тестирования используется GoogleTest (gtest). Тесты находятся в каталоге /test.
Отчёт о покрытии кода формируется с помощью lcov или gcovr.

## Технологии

C++, C++17, Make, GoogleTest
